About the Project

A clean demonstration of DSA concepts in a friendly web layout.

Project Overview

This project combines a simple social network interface with C++ graph logic to recommend people a user might know through mutual connections.

Technologies Used

HTML, CSS, JavaScript, and C++ with graph traversal and adjacency lists.

Core Concepts

The backend uses adjacency lists and breadth-first search to discover relevant second-degree connections and count mutual friends.

Project Outcomes

The result is a polished demo that is easy to understand, visually appealing, and suitable for a college internship presentation.
